## 源代码生成器研究

### 背景
正在写一个通用的保存系统（虽然引擎实现了但是我们这是跨引擎框架……），我们实现了ICanSave定义可以存取什么东西进去，但每次都要实现接口还要写dto很麻烦。所以引入源代码生成器。
用`IIncrementalGenerator`而不是`ISourceGenerator`是因为官方声明后者已经过时了，看别人的博客说如果有热重载，会导致源代码生成器一直工作，进而导致IDE卡死。
unity在2022.3引入了Roslyn Source Generator 4.3.1，`IIncrementalGenerator`变得可用,因此框架也把unity支持最低版本调到了2022.3

### 介绍
援引官方的介绍:

> 增量生成器是一种新的 API，与源生成器一起存在 ，允许用户指定可由托管层以高性能方式应用的生成策略。
>
> High Level Design Goals
> - 允许使用更细粒度的方法来定义生成器
> - 缩放源生成器以支持 Visual Studio 中的“Roslyn/CoreCLR”缩放项目
> - 利用细粒度步骤之间的缓存来减少重复工作
> - 支持生成更多项目而不仅仅是源文本
> - ISourceGenerator与基础实现并存

_高性能就意味着巨**难用（）,不过现在有ai了_

### 管线
增量生成器采用管线的形式。生成器会创建一个管道，从基础输入源开始，并将其映射到它们想要生成的输出。暴露的、完全可比的状态越多，编译器就能越早地停止更改并重用相同的输出。
**这些生成器的运行顺序是无序的。**

这是一个基本的Generator类
```csharp
[Generator]
public class SaveGenerator : IIncrementalGenerator
{
    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
    }
}
```

Initialize负责建立代码生成流程，而且只在Generator实例化期间运行一次，它传入上下文实例，里面是一堆provider，也就是输入数据，具体如下：
- CompilationProvider:拿程序集数据
- AdditionalTextsProvider:读取外部的文件信息
- SyntaxProvider:源码语法筛选能力
- AnalyzerConfigOptionsProvider:编译器及 Analyzer 配置
- MetadataReferencesProvider:被引用的程序集元数据
- ParseOptionsProvider:C# 语法解析配置

常用的是前三个。

下面是使用`CompilationProvider`自动生成hello world的生成器用法。大概意思就是找到定义了Main的类然后直接把代码注入进去。
```csharp
using Microsoft.CodeAnalysis;
using Microsoft.CodeAnalysis.Text;
using System.Text;

namespace HelloWorld_IncrementalGenerator.Analysis
{
    [Generator]
    public class HelloSourceGenerator : IIncrementalGenerator
    {
        public void Initialize(IncrementalGeneratorInitializationContext context)
        {
            // 读取程序集数据
            var compilation = context.CompilationProvider;
            // 注册源代码生成的逻辑
            context.RegisterSourceOutput(compilation, (sourceProductionContext, c) =>
            {
                // 找main入口
                var mainMethod = c.GetEntryPoint(sourceProductionContext.CancellationToken);
                string source = $@"// <auto-generated/>
using System;

namespace {mainMethod.ContainingNamespace.ToDisplayString()}
{{
    public static partial class {mainMethod.ContainingType.Name}
    {{
        static partial void Hello(string name) =>
            Console.WriteLine($""Hello: '{{name}}'"");
    }}
}}
";
                var typeName = mainMethod.ContainingType.Name;

                var sourceText = SourceText.From(source, Encoding.UTF8);
                // 把源代码字符串加入上下文
                sourceProductionContext.AddSource($"{typeName}.g.cs", sourceText);
            });
        }
    }
}

```
### 实践
大部分源代码生成器依赖Attribute标签，我们也是。我希望的工作流是这样的：用`[CanSave(<key:string>)]`标记需要被保存的类，`[SaveField(<Key:int>)]`标记类里面要被保存的字段，
生成器能够读取标记，然后自动帮我实现`ICanSave`接口和需要的DTO`ASaveData`
比如：
```csharp
[CanSave]
public partial class PlayerModel : AModel
{
    [SaveField]
    private int _level;

    [SaveField]
    private string _name;
}

// PlayerModel.g.cs
namespace Game.Models
{
    public partial class PlayerModel : ICanSave
    {
        [MessagePackObject]
        private sealed class PlayerSaveData : ASaveData
        {
            [Key("_level")]
            public int Level { get; set; }

            [Key("_name")]
            public string Name { get; set; }
        }

        public string SaveKey => "player";

        public Type SaveDataType => typeof(PlayerSaveData);

        public ASaveData Capture()
        {
            return new PlayerSaveData
            {
                Level = _level,
                Name = _name
            };
        }

        public void Restore(ASaveData data)
        {
            var save = (PlayerSaveData)data;

            _level = save.Level;
            _name = save.Name;
        }
    }
}
```
首先是收集被标记了[CanSave]的类。
```csharp
var syntax = context.SyntaxProvider.ForAttributeWithMetadataName("ObFramework.Integrated.Save.CanSaveAttribute", // -->读取标签
    static (node, _) => node is ClassDeclarationSyntax,  // -->限定他是类
    static (syntaxContext, _) => syntaxContext.TargetSymbol); // --> 提取匹配类
```
最终返回`IncrementalValuesProvider<ISymbol>`
SyntaxProvider.ForAttributeWithMetadataName是通过Attribute标签筛选的快速方法，还有另外一个CreateSyntaxProvider方法更泛用，使用的方式也差不多。
接下来是筛选`[SaveField(<Key:int>)]`，只需要改造一下上面syntax
```csharp
var syntax = context.SyntaxProvider.ForAttributeWithMetadataName("ObFramework.Integrated.Save.CanSaveAttribute",
// 进一步判断
static (node,_) => node is ClassDeclarationSyntax,
static (syntaxContext, _) =>
    {
         symbol = syntaxContext.TargetSymbol as INamedTypeSymbol; // -->筛出类
         var saveFieldAttributeSymbol = syntaxContext.SemanticModel.Compilation
                                .GetTypeByMetadataName("ObFramework.Integrated.Save.SaveFieldAttribute"); // -->Attribute符号
         var members = symbol!.GetMembers().OfType<IFieldSymbol>(); // -->筛出成员变量
         var attr = members.Where(x => x.GetAttributes()
                    .Any(y => SymbolEqualityComparer.Default.Equals(y.AttributeClass, saveFieldAttributeSymbol)))
                    .ToArray(); // --> 把有标记的成员筛出来
         var ns = symbol.ContainingNamespace.IsGlobalNamespace ? "" : symbol.ContainingNamespace.Name; // -->命名空间
         var name = symbol.Name; // --> 类名
         var key = syntaxContext.Attributes[0].ConstructorArguments[0].Value as string; // --> key
         return (Attrs:attr,Namespace:ns,ClassName:name,Key:key); // -->返回元组
    });
```

然后是注册源代码，把生成的源代码加进去。
```csharp
context.RegisterImplementationSourceOutput(syntax,static (output,models) =>
{
    var source = SaveEmitter.Generate(models.ClassName,models.Namespace,models.Attrs,models.Key!); // 把源码生成逻辑移到静态类里面
    var hintName =$"{models.ClassName}.Save.g.cs"; // 生成类文件名（一般看不到）
    output.AddSource(hintName,SourceText.From(source, Encoding.UTF8)); // 添加源代码
});

using Microsoft.CodeAnalysis;
using System.Text;

namespace ObFramework.Generator.Integrated.Save
{
    /// <summary>
    /// 各种字符串替换
    /// </summary>
    internal static class SaveEmitter
    {
        private const string Template =
@"// auto generated
using MessagePack;
using ObFramework.Integrated.Save;

{{NAMESPACE_BEGIN}}
    public partial class {{CLASS_NAME}} : ICanSave
    {
        [MessagePackObject]
        public sealed partial class {{CLASS_NAME}}SaveData : ASaveData
        {
{{SAVE_FIELDS}}
        }

        public string Key => ""{{SAVE_KEY}}"";

        public Type SaveDataType => typeof({{CLASS_NAME}}SaveData);

        public ASaveData Capture()
        {
            return new {{CLASS_NAME}}SaveData
            {
{{CAPTURE_FIELDS}}
            };
        }

        public void Restore(ASaveData value)
        {
            var data = ({{CLASS_NAME}}SaveData)value;
{{RESTORE_FIELDS}}
        }
    }
{{NAMESPACE_END}}
";
        public static string Generate(string name,string ns, IFieldSymbol[] attrs, string key)
        {
            var sb = new StringBuilder();
            sb.Append(Template);
            sb.Replace("{{CLASS_NAME}}",name)
              .Replace("{{SAVE_KEY}}",key);
            if (!string.IsNullOrEmpty(ns))
            {
                sb.Replace("{{NAMESPACE_BEGIN}}",
@$"namespace {ns}
{{")
                  .Replace("{{NAMESPACE_END}}","}");
            }

            string saveFields = GenerateSaveFields(attrs);
            sb.Replace("{{SAVE_FIELDS}}",saveFields);
            string captureFields = GenerateCaptureFields(attrs);
            sb.Replace("{{CAPTURE_FIELDS}}", captureFields);
            string restoreFields = GenerateRestoreFields(attrs);
            sb.Replace("{{RESTORE_FIELDS}}", restoreFields);
            return sb.ToString();
        }

        private static string GenerateRestoreFields(IFieldSymbol[] attrs)
        {
            var sb = new StringBuilder();
            foreach (var attr in attrs)
            {
                sb.AppendLine($"this.{attr.Name} = data.{attr.Name};");
            }
            return sb.ToString();
        }

        private static string GenerateCaptureFields(IFieldSymbol[] attrs)
        {
            var sb = new StringBuilder();
            foreach (var attr in attrs)
            {
                sb.AppendLine($"{attr.Name} = this.{attr.Name},");
            }
            return sb.ToString();
        }

        private static string GenerateSaveFields(IFieldSymbol[] attrs)
        {
            var sb = new StringBuilder();
            foreach (var attr in attrs)
            {
                sb.AppendLine($"[Key(\"{attr.Name}\")]");
                sb.AppendLine($"public {attr.Type} {attr.Name};");
            }
            return sb.ToString();
        }
    }
}
```
